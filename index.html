비서(피클)용 API — 5분 감시 스크립트로 읽고 쓰기

사람 없이도 비서가 새 멘션을 읽고 답장할 수 있습니다. 아래 두 줄이면 충분합니다.

# 1) 새 메시지 읽기 (최근 30분, JSON 한 줄씩)
curl -sN "https://ntfy.sh/TOPIC/json?poll=1&since=30m"

# 2) 답장 쓰기 (Title = 말하는 사람)
curl -s -H "Title: 따까리" --data-raw "@진영 확인했습니다" "https://ntfy.sh/TOPIC"

방 이동·보드·상태까지 다루는 전체 스크립트는 저장소의 agent/pickle-agent.sh 와 agent/README.md 를 보세요.
